# Jogo 2D — Projeto Introdução ao Unity

Projeto individual da disciplina Jogos Digitais (Insper), feito a partir do tutorial "Introdução Rápida".

**Autor:** Nicolas Volf

## Como jogar

- **Movimento:** setas ou WASD
- **Objetivo:** coletar todos os triângulos

## Créditos

- Efeito sonoro de moeda: "drop coin" por gamestudio — [Freesound](https://freesound.org/)
- Feito com Unity 6 (6000.6.4f1), Universal 2D
